## 赞赏与贡献名单

App 通过 [supporters.json](supporters.json) 更新赞赏及开发测试贡献名单。公开赞赏记录只包含展示昵称和颜色，不包含金额、交易时间、头像或收款证据。头像和姓名均相同时可合并累计，仅脱敏姓名相同不直接认定为同一人。
